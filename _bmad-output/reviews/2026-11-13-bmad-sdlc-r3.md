## Adversarial (12)

- **`.agents/skills/bmad-sdlc/scripts/sdlc_plan.py:2565-2573`, `2696-2704`** — The blocked→passed guard reads only `_gate_status_target(path)`, so a whole-node replacement skips it. Repro: block `tickets.T1.gates.review`, then `set --path tickets.T1.gates.review --replace --value '{"status":"passed"}' --reason probe` → `ok: true`, `validate` clean, `override_reason: null`. Fix: drive `_guard_blocked_gate` from `_written_gate`, as `_guard_reopen` already does. Consequence: a gate blocked on missing evidence is recorded passed through the documented `--replace` form.
- **`.agents/skills/bmad-sdlc/scripts/sdlc_plan.py:2317-2334`** — The dotted-id rejection sits inside `if "gates" in parts`, so a path without a gate segment still splits at the dots. Repro: `ticket --id 1.3 …`, then `set --path tickets.1.3.note --value phantom --replace --reason probe` → `ok: true`; `validate` then errors `workstreams.ws-001.tickets.1.gates must be a mapping`. Fix: reject a dotted id for every `tickets.<id>…` path, not only gate paths.
- **`.agents/skills/bmad-sdlc/scripts/sdlc_plan.py:3112-3146`** — `done` refuses a custom-ledger close before the accept branch: `if ledger_tickets and project_root is None: fail("pass --project-root …")`. Repro: `init --plan <custom>/plan.yaml`, pass the ticket gates, then `done --accept-missing-tickets --reason ledger-only` → still fails. Fix: fold the two branches into one `artifact_tickets is None` check; make `--project-root` a hint, not a requirement, when the gap is explicitly accepted.
- **`.agents/skills/bmad-sdlc/scripts/sdlc_plan.py:2493-2535`, `2945-2958`** — `_guard_reopen` checks later ticket gates but never the workstream state. Repro: close a workstream, then `ticket --workstream ws-001 --id T1 --gate done --status open --reason rework` → `ok: true`; `validate` then errors `phases.close is done while build has undecided gates` and `ws-001 is done with undecided gates: build.T1.done`; `next_action` is null. Fix: refuse a reopen on a done workstream, or reopen the workstream/phase in the same write.
- **`.agents/skills/bmad-sdlc/scripts/sdlc_plan.py:2499-2510`, `2730-2737`, `2961-2966`** — The guard keys on `status == "open"` only, so a decided gate can be demoted to `blocked` with no reason. Repro: `ticket --gate review --status overridden --reason "review waived"`, then `ticket --gate review --status blocked` → `ok: true`, `override_reason: null`, `decided_at` stamped on a blocked gate. Fix: treat every transition out of `passed|overridden|skipped` as a reopen requiring `--reason`, and set `decided_at` only for a decided status.
- **`.agents/skills/bmad-sdlc/scripts/sdlc_plan.py:2403-2411`, `2703-2739`** — A gate-node replacement with no `status` is accepted. Repro: `set --path tickets.T1.gates.ticket --replace --reason compact --value '{"decided_at":null}'` → `ok: true`; `validate` then errors `…gates.ticket.status must be one of open, passed, overridden, skipped, blocked`. Fix: require a valid `status` on any gate-node replacement, routed through the scalar guards.
- **`.agents/skills/bmad-sdlc/references/ledger-schema.md:203-205`** — The example added in this pass removes a ticket by writing a null node, not by deleting the key. Repro of the documented command → `ok: true`; `validate` errors `tickets.1-3-ticket-menu must be a mapping`, and `summary` still offers it. Fix: support deletion (`--delete`, or `ticket --delete`), or show a working removal.
- **`.agents/skills/bmad-sdlc/scripts/sdlc_plan.py:3028-3032`; `SKILL.md:17`; `references/ledger-schema.md:238-240`** — `done` runs `Path(args.project_root).resolve()` on the raw value, but only `--plan`, `--memlog`, and `--template` are token-expanded. Repro: with a real `tickets.toml`, `done --project-root '{project-root}'` reports `no readable ticket artifact`; the real root closes. `SKILL.md:17` says "the script also expands it" without qualification. Fix: expand `--project-root` in every command that takes it, or scope the sentence and substitute at the call site.
- **`.agents/skills/bmad-sdlc/scripts/sdlc_plan.py:2493-2535`, `2576`** — Reopening a decided *phase* needs no reason and logs none; `validate` stays clean. Repro: set every phase done, then `set --path phases.plan.status --value active` → `ok: true`, memlog records only `phases.plan.status=active`. The gate guard's own error tells the agent to "reopen the phase first", so the unguarded path is the documented remediation. Fix: require `--reason` for a decided phase reopen.
- **`references/menu.md`, `SKILL.md:84`, `references/gate-matrix.md`** — `reopen` appears only in a `ledger-schema.md` comment and in code/tests; no menu verb, loop step, or gate-matrix subsection covers it, and no verb covers a phase reopen. Fix: add a reopen row and a short "Reopening" subsection with the legal sequence.
- **`.agents/skills/bmad-sdlc/scripts/sdlc_plan.py:3028-3032`** — `done` does not check that `--project-root` is a directory, unlike `detect`/`init` (`1435`, `1443`). A typo yields "missing evidence"/"no readable ticket artifact" instead of a bad-flag error, inviting an unnecessary acceptance waiver. Fix: validate `is_dir()` and report the searched roots.
- **`.agents/skills/bmad-sdlc/scripts/sdlc_plan.py:3164-3170`** — The close note records the reason but not which gap was accepted. `--accept-missing-evidence` and `--accept-missing-tickets` produce the same `marked done (reason: …)` line, with no ticket or artifact named. Fix: name the waived items before the reason.

- **`.agents/skills/bmad-sdlc/scripts/tests/test_sdlc_plan.py:1884-1886`** — The `set` reopen test ends at `assertTrue(accepted["ok"])`; the ticket twin asserts `override_reason is None` at 1843, so the `set` half of the "reason lives in the audit, not on the gate" rule is unpinned.
- **`.agents/skills/bmad-sdlc/scripts/tests/test_sdlc_plan.py:277-294`** — `test_migrate_materializes_levels_and_tickets` clears the map with `set --path tickets --null --replace`, which the script rejects (`unknown ticket path: tickets`); the test ignores the result.
